Setting up your NFC cards

  1. Use any NFC card writer app (we recommend "NFC Tools")
  2. Write this URL to each card:
    https://app.ratetapmx.com/r/YOUR-SLUG?card=STAFFCODE
  3. Replace STAFFCODE with each team member's code
  4. Test by tapping with your phone!
